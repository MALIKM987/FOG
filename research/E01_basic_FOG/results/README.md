# E01 – Wyniki

**Nie zarejestrowano jeszcze wyników symulacji ani pomiarów Etapu E01.**

Po uruchomieniu eksperymentu utworzymy osobny katalog `EXP-YYYY-NNN/` i zapiszemy w nim:
- parametry wejściowe (np. JSON),
- dane wynikowe (np. CSV, format natywny programu),
- wykresy z podpisami i jednostkami,
- raport na podstawie [szablonu](../../templates/experiment_report.md),
- wersję narzędzia i SHA modelu.

Nie kopiujemy tu bez interpretacji wyników wcześniejszych modeli v1–v8.1. Wyniki nowe będą umieszczane tylko wtedy, kiedy można je odtworzyć i poprawnie odróżnić od pomiaru laboratoryjnego.
