# Tekst pracy magisterskiej

**Status: przyszła redakcja, nie rozpoczęto pisania rozdziałów.**

W tym katalogu będzie powstawał tekst właściwej pracy. Aktualnie znajduje się tu jedynie [proponowana mapa rozdziałów](outline.md).

## Źródło materiału do redakcji

- [Theory](../theory/README.md): wspólne wyprowadzenia i teoria.
- [Research](../research/README.md): eksperymenty, schematy, wyniki i wnioski.
- [Bibliography](../bibliography/README.md): źródła, DOI, BibTeX.
- [Dokumentacja modeli historycznych](../docs/ROADMAP.md): przebieg wcześniejszych symulacji.

Nie przenosimy niezweryfikowanych hipotez do tekstu pracy jako dowiedzionych twierdzeń. Format docelowy (LaTeX, Quarto, DOCX) wybierzemy po ustaleniu wymagań promotora/uczelni.
