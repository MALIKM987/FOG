## Standard notatki teoretycznej

Definicja i znaczenie fizyczne → schemat koncepcyjny → równania i wyprowadzenie → jednostki → zakres ważności → źródła → pytania otwarte.

Każdy wzór musi mieć jawne założenia. Nie wolno nazywać przybliżeń idealnego interferometru charakterystyką rzeczywistego prototypu. Cytowania wymagają weryfikacji publikacji oraz wskazania stron/wzorów przed włączeniem do pracy.
